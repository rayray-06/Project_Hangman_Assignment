# Project Hangman Assignment
## Project_description
> Mobile compatible multiplayer hangman web game (made with python, html, css and javascript)

This project is a mobile-compatible, multiplayer version of the classic Hangman game designed for users aged 13–20. The game allows players to guess letters using an on-screen interface, with correct guesses revealing letters in the hidden word and incorrect guesses reducing the number of remaining attempts. Two players can participate from separate devices by joining a shared game room using a unique room code generated by the host player. Both players interact with the same game state, allowing guesses and game progress to be synchronised in near real time across devices. The game provides immediate feedback for incorrect guesses and displays a clear win or lose outcome when the word is completed or the maximum number of attempts is reached. The application is developed using Python and web technologies, is designed to be usable on mobile devices, and is version-controlled using GitHub.

## Target_users 
The primary target users for this project are people aged between 13 and 20 years old. This age group is familiar with mobile devices and web based games and is likely to enjoy simple interactive games that can be played casually with friends. The game is designed to be easy to understand with clear rules so that new users can start playing without needing instructions. Multiplayer functionality appeals to this age group as it allows them to play together using their own devices rather than sharing a single screen. The visual design and controls are kept simple to make the game accessible and enjoyable on mobile phones.
